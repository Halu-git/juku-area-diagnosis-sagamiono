# 学習塾の出店エリア診断 — 相模大野駅徒歩圏サンプル

公開統計データだけで、学習塾・英会話教室の出店判断をどこまでできるかを検証したサンプルプロジェクトです。
対象は相模大野駅（神奈川県相模原市南区）徒歩圏、「学習塾の2校目を出すべきか」という仮説シナリオで診断しました。

## 解説記事（Zenn）
方法と検証過程を記事にしています：[相模大野駅前の「子どもの数」は増えていた — 学習塾の出店エリア診断を、複数ソースで精査してみた](https://zenn.dev/halu_git/articles/72743491a65bc1)

## 結論
**条件付きで「出す」**
- 学齢人口（6〜15歳・推計）は駅から1km圏で4,618人。2015年→2020年で+9.0%と、総人口の伸び（+5.1%）を上回って増加
- 学校基本調査の実数（2025年）でも検証：圏内の公立小3校1,768人、学区カバー圏では3,309人となり、推計の桁は妥当と確認
- 一方で競合は過密（Web確認48教室、うち相模大野3丁目に集中）。集団指導の正面参入は避け、英語・個別指導での差別化が条件
- 地価公示（2026年）で駅前商業地は前年比+15.4%。駅前1等地にこだわらないことも条件に追加

## 使い方（再現手順）
1. 出典セクションの各データを取得する（いずれも公開データ。e-Stat APIの appID は不要で、公開ダウンロードのみで再現可能）
2. `scripts/` の集計スクリプトを実行する
3. 半径500m／1kmの商圏集計では、メッシュの「重なり方式」を主方式としている（中心点方式との差はレポートに明記）

## データ出典
- 総務省統計局「国勢調査 地域メッシュ統計／小地域集計」（2020年・2015年、e-Stat）
- 総務省・経済産業省「令和3年経済センサス-活動調査」（e-Stat）
- 文部科学省「学校基本調査」学校別集計（神奈川県教育委員会公表、2025年5月1日現在）
- 国土交通省「国土数値情報」学校データ／地価公示データ（2026年地価公示）
- 競合教室の確認：各教室の公式サイト・塾情報ポータル（2026年11月確認）

各データの利用条件・出典表示は、それぞれの提供元の規約に従います。

## 限界（正直な注記）
- 人流データ（昼間人口）は未取得。G空間情報センターの登録が必要で、データ期間も2019〜2021年に限られるため、現在の昼間人口の断定には使っていません
- 不動産の成約価格は未取得（API登録が必要）。地価公示で代替しています
- 私立学校の在籍数は県の公立集計の対象外で未取得です
- 国勢調査の詳細な地域データは2020年が最新です
